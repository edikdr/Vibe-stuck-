# Безопасность

## Что приложение делает с сетью

Оно офлайн-first: без сети работает весь каталог. В сеть оно ходит только тут,
и каждый источник отключается в «Обновлениях»:

| Куда | Зачем | Отключается |
|------|-------|-------------|
| `github.com/.../releases/latest/download/` | манифест и база каталога | «База каталога» |
| `registry.modelcontextprotocol.io` | новые MCP-серверы | «Официальный MCP Registry» |
| `api.github.com` | skills в доверенных репозиториях, звёзды | «Репозитории skills», «Популярность» |
| `registry.npmjs.org`, `pypi.org` | свежие версии пакетов | «Версии пакетов» |
| официальные ссылки записей | проверка доступности | «Доступность ссылок» |
| `s.wordpress.com/mshots`, `image.thum.io` | скриншоты витрин | «Изображения» → `off` |
| свой HTTPS-адрес | пользовательская лента и свой манифест | пустое поле |

Только `https://` — и в коде, и в проверках каталога. Токены и учётные данные
приложение не хранит и не запрашивает.

## Ключи API

В проекте нет и не будет общих секретных ключей. Записи ведут на официальную
страницу регистрации и различают `noKey`, `free`, `freeTier`, `openSource`,
`mixed` и `paid`. PR, добавляющий чужой ключ, будет закрыт.

## Обновление каталога

Каталог — единственное, что релиз может подменить на устройстве без
переустановки приложения, поэтому путь обновления проверяется по шагам:

1. манифест забирается по HTTPS с `github.com`;
2. сверяются `schemaVersion` и `minAppVersion`;
3. сверяются размер и `sha256` скачанного архива;
4. сверяются размер и `sha256` распакованной базы;
5. база открывается, её `meta.catalogVersion` должен совпасть с манифестом;
6. только после этого файл заменяется — одним переименованием.

Провал любого шага оставляет установленную базу нетронутой; временный файл
удаляется.

### Подпись релиза

Шаги выше защищают от порчи файла по пути, но не от того, кто вправе
опубликовать релиз: скомпрометированный токен, ошибка мейнтейнера или сам
хостинг подменят и архив, и его sha256 в манифесте разом. От этого защищает
подпись Ed25519.

Подписывается не файл манифеста, а явная полезная нагрузка из полей, которые
решают, что именно установится:

```
vibestack-atlas-catalog-v1
<schemaVersion>
<catalogVersion>
<size>
<sha256>
<databaseSize>
<databaseSha256>
```

Так сделано, чтобы манифест мог обрасти новыми полями, не сломав подпись у
всех уже установленных приложений: клиент собирает эти строки из разобранных
значений, а не сравнивает байты JSON.

**Правило клиента жёсткое:** если в сборку вшит публичный ключ
(`releasePublicKey`), то каталог **без подписи или с чужой подписью
отвергается**. Подпись, отсутствие которой клиент готов простить, не защищает
ни от чего.

Сейчас ключ пустой — подписывание в проекте не включено, и работают TLS плюс
sha256. Включается это тремя шагами, и порядок важен:

```bash
python3 tool/release_key.py generate      # приватный и публичный ключ
# 1. приватный  -> секрет CATALOG_SIGNING_KEY в настройках репозитория
# 2. публичный  -> data/release-key.pub, закоммитить
# 3. следующий релиз подписывается автоматически
```

Публичный ключ нельзя коммитить раньше, чем секрет появится в репозитории:
приложения из этой сборки будут требовать подпись, которой ещё никто не
ставит. Релизный workflow это проверяет и падает с внятной ошибкой, а не
выпускает релиз, который никто не сможет установить.

Максимальный размер архива ограничен 64 МБ: релиз заметно больше того, каким
каталог когда-либо был, — это ошибка публикации, а не обновление.

## Данные пользователя

Избранное, свои записи и настройки лежат в SharedPreferences, а не в базе
каталога — именно потому, что база целиком заменяется при обновлении.
Аналитики, телеметрии и краш-репортов нет; никакие данные пользователя никуда
не отправляются.

## Как сообщить о проблеме

Приватно — через **Security → Report a vulnerability** на GitHub. Если
приватные отчёты в репозитории не включены, открой обычный issue **без**
деталей эксплуатации и попроси связаться.

Уязвимости в самих каталогизированных сервисах сообщать нужно им, а не сюда;
здесь имеет смысл поправить запись, если сервис перестал быть безопасным
выбором.
